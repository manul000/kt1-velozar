# Велозар

Установите Node.js 22 с npm. Откройте терминал в папке проекта, где находится `package.json`.

Установка зависимостей:

```text
npm install
```

Запуск:

```text
npm run start
```

Откройте http://localhost:3000 или адрес, указанный в терминале. Для остановки нажмите `Ctrl+C`.

Сборка:

```text
npm run build
```

Готовый сайт появится в папке `build`. Открывайте его через веб-сервер, а не двойным щелчком по `index.html`.
